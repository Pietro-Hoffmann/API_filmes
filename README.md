# Movie Catalog

Single-page movie catalog built in React — search a film API, browse results in a
responsive grid, and open any title for details.

## Features

- Search with results rendered as a responsive card grid
- Detail modal per title
- Loading states while requests are in flight
- Data fetching isolated in a `useMovies` hook, so components stay presentational

## Stack

**React** · **TypeScript** · **Vite** · **Tailwind CSS**

## Running locally

```bash
cd filmes
npm install
npm run dev
```

> Built as a study project in React and API consumption.
